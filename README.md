Промпт для генерации отклика на заказ на бирже фриланса
=======================================================

Принимает в качестве аргумента параметр order_text с текстом заказа,
взятым с биржи фриланса, возвращает в ответе текст отклика на заказ,
который с большой вероятностью заинтересует клиента.

Основной шаблон промпта находится в файле prompt.txt. Для формирования
итогового промпта для LLM в него нужно подставить правильное значение
order_text - текст заказа.

Файлы, включенные в репозиторий
-------------------------------

*   prompt.txt
    Шаблон промпта

*   generate_response.py
    Программа для тестирования промпта

*   requirements.txt
    Список пакетов, от которых зависит generate_response.py, нужно установить
    для использования программы

*   README.md
    Файл с инструкцией к промпту

*   .env.example
    Пример файла окружения, необходимого для запуска grnerate_response.py,
    нужно скопировать его в файл .env и прописать правильный API ключ

*   examples/
    Примеры заказов, на которые должны формироваться отклики при тестировании

*   .gitignore
    Файл с опциями для управления системой контроля версий, для пользователя
    интереса не представляет.


Использование generate_response.py
--------------------------------

Прежде чем запускать generate_response.py необходимо выполнить следующее:

-   создать виртуальное окружение и установить зависимости командами
    `python3 -m venv venv`
    `source venv/bin/activate/`
    `pip install -r requirements.txt`

-   Установить необходимые SSL сертификаты для доступа к API GigaChat

-   Создать файл .env на основе .env.example, прописав в него API ключ для
    доступа к API GigaChat.

Для запуска generate_response.py необходимо сначала сохранить текст заказа в отдельном
файле - например, order.txt, а затем вызвать generate_response.py, передав в качестве
аргумента имя этого файла - например, `python generate_response.py order.txt`.

В ответ на экран будет выведен текст возможного отклика на заказ.
