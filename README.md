Промпт для генерации отклика на заказ на бирже фриланса
=======================================================

Принимает параметры `skills_text` с описанием навыков фрилансера и
`order_text` с текстом заказа, взятым с биржи фриланса, и возвращает
в ответе релевантность заказа навыкам исполнителя и текст отклика на заказ,
который с большой вероятностью заинтересует клиента. Текст отклика на
заказ генерируется только в случае если релеватность заказа навыкам
пользователя больше порогового значения `min_relevance`.

Основной шаблон промпта находится в файле prompt.txt. Для формирования
итогового промпта для LLM в него нужно подставить правильное значение
для следующих параметров:

*   `skills_text` - описание навыков исполнителя;

*   `order_text` - текст заказа;

*   `min_relevance` - минимальная степень соответствия заказа навыкам
    пользователя от 0 до 100, при которой отклик на заказ будет
    сгенерирован;

*   `name` - имя исполнителя - необязательно, используется для подписи.

Файлы, включенные в репозиторий
-------------------------------

*   prompt.txt
    Шаблон промпта

*   generate_response.py
    Программа для тестирования промпта

*   requirements.txt
    Список пакетов, от которых зависит generate_response.py, нужно установить
    для использования программы

*   README.md
    Файл с инструкцией к промпту

*   .env.example
    Пример файла окружения, необходимого для запуска grnerate_response.py,
    нужно скопировать его в файл .env и прописать правильный API ключ

*   example-orders/
    Примеры заказов, на которые должны формироваться отклики при тестировании

*   example-skills/
    Примеры описания навыков фрилансера, на основе которых формируется отклик

*   .gitignore
    Файл с опциями для управления системой контроля версий, для пользователя
    интереса не представляет.


Использование generate_response.py
--------------------------------

Прежде чем запускать generate_response.py необходимо выполнить следующее:

-   создать виртуальное окружение и установить зависимости командами
    `python3 -m venv venv`
    `source venv/bin/activate/`
    `pip install -r requirements.txt`

-   Установить необходимые SSL сертификаты для доступа к API GigaChat

-   Создать файл .env на основе .env.example, прописав в него API ключ для
    доступа к API GigaChat.

Для запуска generate_response.py необходимо сначала сохранить текст заказа в отдельном
файле - например, order.txt. Также необходимо записать отдельный файл с описанием
своих навыков и опыта, например, skills.txt. После этого нужно вызвать generate_response.py,
передав в качестве аргументов сначала имя файла с описанием навыков, потом - с текстом
заказа. Например, `python generate_response.py skills.txt order.txt`. Чтобы добавить
имя исполнителя в подпись, используйте дополнительно параметр командной строки `-n`.
Например, `python generate_response.py skills.txt order.txt -n Александр`

Несколько примеров в каталогах `example_skills/` помогут вам грамотно написать файлы с
описанием своего опыта.

В ответ на экран будет выведено значение степени соответствия заказа навыкам пользователя
по шкале от 0 до 100 и текст возможного отклика на заказ. Если степень соответствия заказа
навыкам пользователя меньше 50% то текст отклика на заказ не генерируется и выводится
сообщение о том, что на этот заказ откликаться не стоит.


Примеры работы ассистента
-------------------------

В каталоге `example-skills/` находится пример файла с описанием навыков фрилансера.
В каталоге `example-orders/` находится три примера текста заказов и сгенерированных
откликов на эти заказы. Все отклики были сгенерированы для навыков исполнителя, указанных
в файле примера `example-skills/example-django.txt`.

*   Пример `example-orders/example-django-site/` для заказа, идеально соответствующего
    указанным навыкам, но описанного достаточно кратко, без подробного технического
    задания.

*   Пример `example-orders/example-generic-site/` для более сложного заказа, для которого
    навыки исполнителя в основном подходят хотя может потребоваться также изучение
    некоторых новых библиотек и API.

*   Пример `example-orders/example-laravel-site/` для заказа, стек технологий которого
    совершенно не соответствует навыкам исполнителя. Для этого заказа оценка релевантности
    не превосходит порога в 50% и отклик не был сгенерирован.

Во всех примерах файл `order.txt` содержит текст заказа, `response.txt` - сгенерированный
текст отклика, а `no-response.txt` текст ответа ассистента с отказом генерировать отклик.


Известные ошибки и ограничения
------------------------------

*   Используйте только модель GigaChat-2-Max или GigaChat-2-Pro для адекватной оценки
    релеватности заказа навыкам исполнителя и соблюдения формата ответа. Модель GigaChat-2
    неверно оценивает соответствие заказа вашим навыкам и склонна составлять неадекватные
    отклики, если заказ навыкам не соответствует.
