Версия 1.1
----------

По сравнению с версией 1.0.1 внесены следующие изменения:

* параметр максимальной длины ответа в символах max_output_chars сделан
  настраиваемым;
* добавлены дополнительные файлы документации - Project overview,

Версия 1.0.1
------------

По сравнению с версией 1.0 внесены следующие изменения:

* благодаря более гибкому алгоритму разбора ответа Json теперь можно использовать
  модель GigaChat-2-Pro, а не только GigaChat-2-Max;
* для каждого примера заказа добавлен и пример сгенерированного отклика на этот заказ;
* более подробно описана в документации специфика каждого из примеров заказов.

Версия 1.0
----------

Промпт для генерации отклика фрилансера на заказ.

Внесены следующие изменения по сравнению с версией 0.3.2:

* оценивается соответствие заказа навыкам исполнителя;
* отклик генерируется только если степень соответствия заказа навыкам достаточна;
* используется модель GigaChat-2-Max.

Версия 0.3.2
------------

По сравнению с версией 0.3.1 больше не выводится сам промпт, отправляемый модели,
который раньше выводился на экран в целях отладки.

Версия 0.3.1
------------

Правки по сравнению с версией 0.3:

* поправить промпт, добавив требование не придумывать примеры работ.
